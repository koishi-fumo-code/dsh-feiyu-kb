# 刷视频这一轮的额外约定（给被唤醒的 agent）

> 这份文件放在 bili-whale 的会话工作目录里，DSH 每轮会把它注入进来。
> 它不改变你的人设和任务，只多说一件事：**把有价值的视频沉淀进大肥鱼知识库**。

## 每轮挑中视频之后，多做一步：归档进知识库

对**每一条你认为有知识含量**的视频（档位「值得看 / 可以看」），调用 `kb_add` 存一条：

```
kb_add({
  title:   "<视频标题>",
  bvid:    "BVxxxxxxx",
  up:      "<UP主>",
  url:     "https://www.bilibili.com/video/BVxxxxxxx",
  kind:    "知识",
  tier:    "值得看",              // 或「可以看」
  tags:    "3~6 个，逗号分隔",     // 例：推理,KVCache,DeepSeek
  summary: "一句话：这条到底讲了什么",
  points:  "要点一\n要点二\n要点三",   // 一行一条
  excerpt: "字幕里最关键的原话（可选）"
})
```

规则（很重要，别省也别编）：

- **要点必须是你真的从字幕 / 热评里读到的**。读不到就只写 `summary`，末尾注明「仅标题/简介」，**不许拿标题硬凑**。
- **同一 BV 再写是更新**（后端会合并），所以"以后再补两条要点"随时可以。
- 那种**纯整活、没有知识含量**的（`kind: 有意思`），可以存也可以不存；存了就标 `kind: "有意思"`，不要算作知识。
- 归档完，再调一次 `kb_related`（`text` 用标题 + 要点，`tags` 用刚打的标签，`exclude` 传这条 BV）：
  如果库里有同主题的旧笔记，就在日记里顺手带一句「参考：<旧标题>」—— 让旧知识被重新想起来。
- 顺手把「已归档 N 条」记在你自己的日记里（**日记是给人看的**，不用写技术细节）。

## 挑什么归档（口味）

**第一优先级：看 `~/.dsh/bili-whale.config.json` 里的 `preferences.like / dislike`** —— 那是主人自己写的口味，比你的判断准。

在此之上，按这个顺序：

1. **有用的**（默认该归档）：DSH / 插件 / AI 工具、技术实现、排错方法、有实操细节的教程。
   这类哪怕播放量很低、UP 主很小，只要**方法能复用**就收。
2. **有意思的**（`kind: "有意思"`）：鬼畜、怀旧剪辑、猫咪、整活名场面 —— 和上面偏好对得上就收，
   但**只收"能让他笑一下"的**，不收"看标题就知道什么内容"的流水线作品。
3. **要慎重的**：**纯成果展示**（手工做了个东西、画了张画、搭了个模型）——
   只有当你从字幕 / 热评里读到了**可复用的方法或结论**（例："微缩模型的真实感全靠参照物"），才收；
   如果只是"做得真好"，**不收**（那不是知识，是作品）。
4. **一律不收**：纯搬运合集、标题党、广告带货、吵架吃瓜、直播切片里的闲聊。

数量：**每轮 0~3 条**。没有值得的就写 0 条，**别为了凑数去收** —— 空着比塞满有用。

## 每轮最后：写一份「观察笔记」到 notes/ 里（给兜底用的）

`kb_add` 万一调不通（工具没挂上、你没权限、或者你这轮压根没挑中），知识就白刷了。
所以再加一层兜底：**每轮结束时**，往这个工作目录下的 `notes/YYYY-MM-DD.md` 追加一段。

- 今天的日期用系统日期（例：`notes/2026-10-29.md`）；**同一天就往同一个文件里追加**，别新建第二个。
- 格式**必须**是：一级标题 + 一句结论 + 最多 3 条要点，三五行为止：

```markdown
# 2026-10-29 看过的东西

今天主要在看 <主题>：<一句结论，说清这轮到底看到了什么>。

- 要点一（具体、可验证，别写"很有收获"这种空话）
- 要点二
- 要点三
```

- 这份笔记会在 10 分钟内被知识库的「目录同步」自动收走，所以：
  - **只写值得回看的**，别把流水账抄进去；
  - **不要写隐私**（账号、路径、私聊内容）。
- 你已经用 `kb_add` 归档过的视频，这里可以只写一句「已归档 N 条」+ 主题，不用重复要点。

## 边界

- 知识库根目录：`D:/dsh工作区/大肥鱼知识库`（由插件配置决定，别自己改）。
- 只写知识、**不要**把使用者隐私（账号、路径、私聊内容）写进知识库。
- 知识库是"长期资产"，日记是"当天流水"：**两者别混**——日记里写发生了什么，知识库里只留值得回看的东西。
